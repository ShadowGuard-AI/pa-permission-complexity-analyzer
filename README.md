# pa-permission-complexity-analyzer
Analyzes the complexity of permission configurations (e.g., number of groups, levels of inheritance) and assigns a complexity score to highlight potentially problematic areas. - Focused on Tools for analyzing and assessing file system permissions

## Install
`git clone https://github.com/ShadowStrikeHQ/pa-permission-complexity-analyzer`

## Usage
`./pa-permission-complexity-analyzer [params]`

## Parameters
- `-h`: Show help message and exit
- `-i`: No description provided
- `-v`: Enable verbose output.
